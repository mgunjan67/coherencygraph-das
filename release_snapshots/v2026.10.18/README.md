# CoherencyGraph-DAS: bounded covariance/filtering evaluation

This is an unpublished local scientific candidate. It does not claim journal
acceptance, a new public release, real-time earthquake warning, earthquake
prediction or neural superiority. Manuscripts and submission files are separate.

## Numerical replay from an independent directory

Extract into a new directory. Use Python 3.12 and the pinned saved-table replay
dependencies in environment/replay-requirements.txt. Run from any directory:

    python /path/to/package/replay_all.py --package-root /path/to/package --output-dir /path/to/new-output

This verifies every archived file hash, recomputes original Cook event contrasts,
reference/support controls, saved complex-wave simulation summaries, repeatability,
gauge-support contrasts and all Greek component-score summaries. It independently
recomputes all four dates' mean/marginal-tail frontier memberships and exact paired
case classifications. It does not import the audited October13 analysis helpers.

The preserved October13 analysis/verifier sources retain historical absolute
paths and the original runtime-ledger gate. They are provenance, not the portable
entry point. The portable commands above have no dependency on those paths.

## Archived neural inference smoke

The complete analytical dependency lock is requirements-revision.lock.txt. Its
CUDA-specific torch build is platform-dependent; CPU execution of the installed
build and exact actual versions are recorded in the verification receipts. A fresh
CPU-only wheel installation is not claimed.
To run a single saved statistical feature case through the three local-input
checkpoints and both route flags, add --with-inference-smoke. No raw samples,
optimization or training are used. The fixture contains statistical features and
expected kernels, not waveform excerpts. One smoke case is not full model testing.

## Scientific interpretation

Q is target/reference power contrast, not desired-earthquake SNR. The Greek
component experiment uses prescribed desired wavelets against recorded backgrounds
which can contain natural seismic signals. Four recording dates, not 777,600
nested designs, are the field clusters. Marginal fifth/95th quantile frontiers are
not joint protection probabilities or deployment safety guarantees. Retained
unfavorable comparisons and tail failures are part of the result.

## Late bounded extension

EXTENSION_INVENTORY.json states explicitly whether an extension is included.
Only listed author-code/derived-statistic assets are added by the bundle builder;
no directory-wide sweep of private files occurs. Extension validity, execution,
result regeneration and display mapping are separate checks. If no extension is
included, this package does not pretend to reproduce one.

When both October18 scalar panels are included, replay_all.py automatically runs
portable_extension_replay.py. This independently recomputes the 864,000-row
expanded Ricker panel (777,600 old plus 86,400 comparator rows), 200 date/method
summaries and 40 frontier counts, then the 23,040 recorded-component rows into
all hour/date/source summaries, paired contrasts and cancellation diagnostics.
It imports neither the original scorer nor the summary helper and requires no
waveform arrays. Its default 1e-10 comparison tolerance is numerical, not a
scientific superiority threshold. The original nine-method panel is preserved
separately from the ten-method follow-up.

The recorded-wavefield panel measures a known added excerpt against a fixed
conventional steered reference. The excerpt can contain natural background;
the reference is not clean earthquake ground truth. Two source earthquakes share
one recording date; crossed sources/background dates are not eight independent
earthquakes. Its original waveform/filter runners retain absolute path scope
seals as provenance, not portable execution promises. For waveform-to-case work,
obtain exact provider/example archives, map paths explicitly and verify retained
input hashes. The portable saved-statistic entry point needs none of those arrays.
