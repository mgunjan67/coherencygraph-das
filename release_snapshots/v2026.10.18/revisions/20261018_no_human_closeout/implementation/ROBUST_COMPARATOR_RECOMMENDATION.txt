Mathematical definition, fixed before any new field outcome
---------------------------------------------------------
For each archived active Fourier frequency f, assume a_j=exp(-2*pi*i*f*tau_j).
Use q_j=(j-15.5)/15.5 for the existing 32-channel linear-index injection design.
Set C=[a,q*a], g=[1,0], and solve

  min w^H R_loaded w subject to C^H w=g,
  w=R_loaded^-1 C (C^H R_loaded^-1 C)^-1 g.

R_loaded is the existing context_0.25 matrix plus 0.001*trace(R)/32*I.
Cholesky solves are used; no inverse/pseudoinverse or constraint-dropping fallback.
One numerical constraint-refinement step preserves the same KKT subspace.

The additional complex null constraint has a direct, limited physical meaning:
  - Response a*(1+alpha*q) is preserved exactly for any scalar alpha.
  - For response a*exp(-2*pi*i*f*epsilon*q), the first delay derivative vanishes.
  - An explicit quadratic remainder bound is implemented and tested.
  - This is NOT immunity to arbitrary DAS amplitude/delay variation, scattering,
    near-field waves, or waveform mixtures. It consumes one spatial degree of
    freedom and may increase recorded-background leakage.

q is a normalized index coordinate only because the archived designed responses
use channel-index gradients. A real geographical steering study would require
measured ENU tangent constraints, with independent noncollinear tangents retained.
It must not silently reuse q as a claimed real ray/geometry uncertainty model.

Real recorded-wavefield transplantation: feasibility and limits
--------------------------------------------------------------
This can avoid manual phase labels ONLY if the endpoint is reframed as recovery
of a known ADDED recorded wavefield, not accuracy of an unknown real S onset.
All32-channel empirical samples of a fixed source window are retained separately
and added linearly to a disjoint recorded target/background; the exact added array
is known even when it includes source-window background. Filter the added and
background arrays separately with the same frozen past-only weights, as above.

The scientific statement must be "recorded-wavefield recovery in a controlled
transplant", not clean-earthquake ground truth or real deployment success.
The source window contains its own unseparated natural background; no analyst
can label that clean signal without evidence. Background target windows likewise
need not be earthquake-free. A common unweighted reference output is a fixed
linear functional of the known component, not unknown clean strain.

Source-eligibility assessment is owned by the separate data audit. This helper
does NOT nominate attractive waveforms or bypass its exclusions. If only one
eligible earthquake exists, eight apertures or eight backgrounds cannot be
reported as eight independent earthquakes. Source/background blocks, amplitude
convention, catalog-guided response and all exclusions must be frozen before the
first comparison. No unlabeled waveform may be silently called manual truth.
