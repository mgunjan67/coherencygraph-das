FINITE NO-HUMAN-LABEL EVIDENCE PATH AUDIT
18 October 2026 | CoherencyGraph | BSSA candidate development

DECISION

CONDITIONAL GO for a fixed, recorded-component transplantation case study.
NO GO for interpreting the same exercise as clean earthquake recovery, actual
phase-arrival accuracy, untouched confirmation, continuous false-alarm control,
earthquake prediction, or demonstrated Q1/BSSA significance.

Two catalog-identified earthquake recording examples already exist in the
complete cached source release. They are temporally separate from all ten
previously exposed development background caches. Their exact digital arrays
can be treated as known added components in a mathematically controlled mixture,
without requiring newly created human phase labels. This changes the observable:
it measures fidelity to the injected recorded component, not fidelity to an
unknown clean physical earthquake signal. That distinction must be retained in
the title, abstract, figure captions and conclusion wherever applicable.

The main agent must freeze and authorize the exact bounded implementation before
sample decoding or any experiment. This audit has not run that experiment.

5. WHAT THE RECORDED-COMPONENT TEST CAN MEASURE WITHOUT HUMAN LABELS

Use the complete multichannel band-limited source snippet as z(t), including
its recorded ambient content. Combine it with separately acquired background
n(t) as x(t)=a*z(t)+n(t). Derive every method's covariance and weights solely
from the same past background, before inserting z into the evaluation target.
Apply the frozen linear filter separately to z and n as well as their sum.
An additivity test then makes component accounting exact for the digital mixture.

A desired scalar reference must be specified before outcomes, e.g. the common
conventional steered sum of z under the same catalog-conditioned response.
Then weighted-source distortion relative to that declared scalar reference and
background rejection are measurable. This is fidelity relative to a recorded
component/conventional projection. It is not true single-channel ground motion,
calibrated strain, physical desired-SNR, or a separately observed clean earthquake.

Preserve measured source amplitudes and relative phases across channels. Do not
turn the real record into another rank-one Ricker/plane wave by imposing an ideal
response. No automatic picker is required unless the retained claim specifically
concerns phase accuracy. Catalog-based steering remains an assumption; source
location does not determine exact apparent slowness at the cable. Any selected
travel-time model, phase convention and delay sign must be frozen and shared.

The strongest honest finite question is whether conclusions from ideal wavelet
components remain qualitatively consistent when the added component has real
recorded spatial complexity. Include neural, same-feature ridge, conventional,
same-fraction measured-context and selected/strong measured-context comparators.
Do not add a hybrid or tune loading/steering to rescue neural superiority.
Report each source and background date separately, plus complete aggregation.
If neural loses, retain the loss; the result can strengthen the negative-method
evaluation paper, but not a claim of successful AI earthquake prediction.

6. RESOURCE ARITHMETIC, NOT A RUNTIME PROMISE

All four compressed HDF members sum339,679,587 bytes as files and337,241,133
bytes inside ZIP. Full decoded RawData arrays would total930,000,000 bytes;
there is no reason to decode all channels. Four full-time 381-channel ROIs total
45,720,000 int32 logical bytes. The two proposed7-s ROIs total5,334,000 bytes;
their25-Hz float64 versions total1,066,800 bytes. Two source cases x8 apertures
x175 samples x32 channels in float64 total716,800 bytes.

HDF chunk granularity matters: the proposed crops intersect68 chunks each and
would decompress35,639,616 int32 bytes in total, not merely5,334,000 bytes.
ZIP-level seeks may also scan much more compressed input. A bounded implementation
can extract only the first HDF of each pair if needed (~171 MB files), then read
only these crops plus explicitly justified resampling support. Do not unpack all
archive data. Final filter resampling support and transient handling must be locked
before compute. Reusing archived covariance predictions can avoid training, but
the implementation must prove identical method inputs and correct phase mapping.

No wall-time forecast follows from these byte counts. Measure the source decode
and one finite deterministic case under a watchdog before a larger fixed batch.
Source component tests do not require the continuous797-beam scan and must not
inherit its detector estimand or untouched-validation language.

The root requested extraction implementation, without authorizing its execution
in this subtask. prepare_source_components.py has now sealed the source rules,

their source hashes. Horizontal ray parameters passed the same central finite-

The optional extractor requires an exact SHA256-bound parent protocol under this

It streams and retains only each selected first HDF member (combined171,385,445

Both crop-local25-Hz output grids are documented separately from the relative

not a new latency/preservation guarantee. Extraction has NOT been run by this

8. FINITE STOPPING AND CLAIM CLOSURE

Technical source gate now closed at metadata level:
  Exact eligible members/events, units, sample shapes, clocks, channel IDs,
  overlap, exposure and byte limits are source-bound and machine-readable.
Remaining objective QC before outcomes:
  Actual requested sample/timestamp coverage; no compromised samples in retained
  support; finite values and rails; declared resampling/transient support;
  geometry mapping; model/feature hashes; pre-outcome protocol and resource cap.
  If either source fails, stop/report the failed planned case; do not replace it.

Scientific claim gate can close without new human labels only if the retained
claim is digital-component preservation/rejection relative to a declared reference.
If the manuscript retains actual phase accuracy, real clean-earthquake recovery,
warning, or broad generalization, these two examples do not close it. Narrow the
claim honestly or leave the stronger claim blocked with its exact evidence need.

Editorial significance remains separate from computational validity. A transparent
negative result with a robust comparator and recorded-component sensitivity check
may be publishable, but neither two examples nor passing software tests certify
that BSSA will send it to review. Do not promise a top-quartile acceptance outcome.
